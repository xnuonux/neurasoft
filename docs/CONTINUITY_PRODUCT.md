# Product direction

The working **Eternities Continuity** proposal is maintained in the companion
`xnuonux/eternities-canon` review branch at `products/continuity.md`. It covers the
company-context/publication loop, tiered approval, agent bootstrap, privacy, and
portfolio deployment verification. It is a proposal, not a launched service.

This repository implements only the staged publication and three-dependency review
prototype described in [CONTINUITY.md](CONTINUITY.md).
